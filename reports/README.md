# Local reports

Generated figures, HTML reports, prediction galleries and audit outputs are stored here locally and are excluded from Git because they may contain private AOI imagery or machine-specific paths.

The repository README contains a compact, de-identified summary of the main experimental results.

Authorized derived reports and run records are distributed as a private Release attachment after local absolute paths are removed from the release copy. Source reports remain unchanged locally; package details are in [`../docs/PRIVATE_RELEASE.md`](../docs/PRIVATE_RELEASE.md).
